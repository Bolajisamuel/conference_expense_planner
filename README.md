# Conference Expense Planner

A React front-end app that helps users estimate the cost of hosting a conference at a convention center. Users pick venue rooms, add-ons and meals, and see live totals and a full cost breakdown.

## Features

- Landing page with a Get Started button
- Venue room selection with increment and decrement buttons
- Add-ons selection (speakers, microphones, whiteboards, projectors, signage)
- Meals selection based on the number of people
- Live subtotal for each section
- Show Details pop-up with a table of unit cost, quantity and total cost, plus the grand total

## Built With

- React (function components and `useState`)
- Vite
- Bootstrap
- CSS

## Getting Started

```bash
git clone <your-repo-url>
cd conference_expense_planner
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.

## What I Practiced

- Building and organizing function components
- Managing state with `useState`
- Rendering lists with `map()`
- Calculating totals with `reduce()`
- Conditional rendering for the pop-up
